# AHEAD step-size policy (mprop) — minimal reproducible release

This section reproduces and
uses `checkpoints/kfree_ddpm_style_presolved_ddpm.pt` — the learned
step-size policy behind the "AHEAD" numbers reported in the paper's
Gurobi-backend acceleration table. 

## What the model is

A tiny MLP, `KFreeStepPolicyNorm`, that at each PDHG
unroll step predicts two scalar multipliers `(u2, u8)` on top of the
standard spectral-bound primal/dual step sizes.


## Step 1 — generate the training data (not bundled, ~714 MB)

The 197 presolved training instances are **not** included in this release
(too large for a code submission) -- regenerate them locally instead. Every
step is seeded and deterministic, so this reproduces the same data used for
the bundled checkpoint:

```bash
cd mprop_step_policy
NPROC=8 python data_generation/gen_presolved_train_data.py
```

Each `.npz` holds one **already-presolved** mprop LP (packing-type:
`min c'x s.t. sum(x)=S, Ax<=b, x>=0`, generated by `scaling_n_mprop.py`,
`m = ceil(0.1*n)`, ~100 nonzeros/row, then reduced via Gurobi's own
`model.presolve()`), plus a **certified exact** label `(x*, y*)` from the
restricted-LP + full-problem-certificate procedure (`restricted_start.py`,
tolerance < 1e-5 on primal/dual feasibility and the duality gap). Keys:
`A_data, A_indices, A_indptr, A_shape` (CSR), `b`, `c`, `lb`, `ub`,
`num_equalities`, `x_star`, `y_star`, `n_orig` (the original, pre-presolve
problem size, `n ∈ [1e5, 1e6]`, log-uniform — see
`data_generation/mprop_eval_split_large.py`, `SPLIT_SEED=12345`).

## Step 2 — train the policy

```bash
cd mprop_step_policy
EPOCHS=60 TAG=presolved_ddpm python train_step_policy.py
```

Requires: `torch`, `numpy`, `scipy`, a CUDA GPU (falls back to CPU
automatically but will be slow), and the compiled `../common/cuPDLP_torch/eigen_spmv*.so`
extension.

## `data_generation/` (required — Step 1 above)

- `scaling_n_mprop.py` — the mprop packing-LP generator
- `mprop_eval_split_large.py` — defines `MPROP_TRAIN_PAIRS` (the 200
  candidate `(n, seed)` pairs, `SPLIT_SEED=12345`; 197 of them certify)
- `restricted_start.py` — the certified-restricted-LP exact-label recipe
- `gen_highprec_labels_presolved.py` — `presolve_to_qp`, the Gurobi
  presolve-extraction step
- `gen_presolved_train_data.py` — orchestrates the three files above into
  `data/presolved_train/*.npz` (parallel, `multiprocessing`) — **run this
  first** (Step 1)
- `certified_train_pairs_197.json` — the exact 197 `(n, seed)` pairs that
  certified in our original run, for verification
